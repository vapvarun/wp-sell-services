## G2 - Authorisation

`tests/audit/rest-reachability.php`: 188 routes across `wpss/v1` and `wpss-pro/v1`, every route has a permission callback, no GET answers 5xx.

## G3 - Reviewed diff

Changes touching money or access, reviewed this cycle:
- `mark_as_paid` and `wpss_ensure_pay_order` now refuse cancelled, refunded and locked-phase orders (narrows what can be paid; no new route).
- `DeliveryService::submit` refuses a whole delivery when any file fails `wpss_check_upload` (tightens uploads).
- `wpss_withdrawal_processed` carries the new status and note to listeners; the audit log keeps `previous_status`.
- The automated security review of the withdrawal change found the audit-log `from_value` regression; fixed before tagging.

## Fixed during the gate

- Free: `AbstractPaymentGateway` used `WP_Error` and `WP_REST_Response` without importing them, so the offline gateway error path would have fataled. Imported.
- Free: three class files gained the direct-access guard.
