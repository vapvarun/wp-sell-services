# Security review - 1.9.1 (Free and Pro)

Reviewed 2026-10-21 against v1.9.0. Blocking findings: none.

## G1 mechanical sweep (`security-sweep.sh --baseline v1.9.0`)

No category grew against v1.9.0. One CRITICAL-class count went down: `ajax-nopriv` 7 to 6, because the review Helpful AJAX action was removed. The six remaining `wp_ajax_nopriv_` handlers are unchanged since 1.9.0 (public search, cart and checkout entry points); each is rate-limited or read-only and was triaged in `1.8.0.md` and `1.9.0.md`.

## G2 authorisation

- `audit/route-authority.json` was updated in this release: the Helpful route is gone; no route was added. The two new query args on `GET /wallet/transactions` (`from`, `to`) sit behind the existing logged-in gate and the query stays scoped to the caller's `user_id`.
- Report resolution: `/reports/{id}/resolve` and the admin Resolve button are admin-only (`wpss_rest_require_admin` and the admin page capability) and share one writer, `ReportsController::resolve_report()`.
- Suspended vendors: `ConversationService::standing_block` now also refuses a vendor suspended on the profile row, so a suspended seller cannot start a pre-sale conversation (REST and the Contact Seller AJAX path).

## G3 reviewed diff

| Surface | Result |
|---|---|
| Ledger period filter | `from` and `to` are validated by a `^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$` pattern and added through `$wpdb->prepare()`. |
| Vendor social links | Saved through the existing `PUT /vendors/me`, keys `sanitize_key`, values `esc_url_raw`. The dashboard form escapes with `esc_url`. |
| Contact Seller attachments | Unchanged validation (`wpss_handle_message_attachments`); the response now also lists skipped files by name. A disallowed `.exe` was refused in a browser run. |
| Number settings | The sanitizer clamps to each field's min and max, which closes negative order limits. |
| Review notices | A held review sends nothing until approved, so a rejected review never reaches the seller. |
| Helpful removal | Route, AJAX action, cron job and `_wpss_vote_*` options removed; upgrade deletes the options. |
| Stale vendor link | Adds `noindex` through `wp_robots`; no output of user input. |

## Scanner-visible but safe

- `nonce-only-auth` (99): each handler also checks capability or ownership; unchanged count except one fewer.
- `sql-direct-interpolated` (33): table names and prepared fragments only; unchanged.
- `files-superglobal` (22) and `upload-no-filetype-check` (1): unchanged from 1.9.0, validated through `wp_check_filetype_and_ext` and the attachment handler.

## Not covered

No external reporter this cycle. Pro was reviewed by the diff only (ledger range filter, Woo order line name, EDD service count).
